# Linux Security Monitoring & SSH Authentication Investigation Lab

## Project Overview
This project demonstrates basic Linux security monitoring and SSH authentication investigation using an Ubuntu virtual machine.

## Objectives
- Monitor SSH authentication events.
- Identify successful and failed login attempts.
- Review Linux authentication logs.
- Document findings using a basic SOC investigation workflow.

## Lab Environment
- **Operating System:** Ubuntu 22.04.5 LTS
- **Virtualization:** VMware Workstation
- **Service:** OpenSSH
- **Log Source:** `/var/log/auth.log`

## Investigation Summary
A controlled failed SSH login was generated by entering an incorrect password. Authentication logs were reviewed to identify the event and its source.

The investigation identified:
- Successful SSH authentication for `mahesh`
- Failed SSH authentication attempts for `mahesh`
- Source address `127.0.0.1` (localhost)

## Key Findings
The activity originated from the same Ubuntu virtual machine. The failed attempts were part of a controlled lab exercise and do not indicate an external attack.

## Skills Demonstrated
- Linux command-line basics
- SSH service verification
- Authentication log analysis
- Basic event timeline creation
- Security evidence documentation
- SOC investigation fundamentals

## Recommendations
- Use strong, unique passwords.
- Prefer SSH key-based authentication where appropriate.
- Monitor repeated failed authentication attempts.
- Restrict SSH access to trusted networks when appropriate.

## Conclusion
This lab provided hands-on practice with SSH authentication monitoring, Linux log analysis, and basic incident documentation.
